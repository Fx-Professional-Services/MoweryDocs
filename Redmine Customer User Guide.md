# Redmine Customer User Guide

This guide shows you how to access your Redmine project, view Issues and Features, add comments, attach files, and check updates.

## 1. Sign In

1. Open the Redmine website provided by FX Professional Services.
2. Enter your **Username** and **Password**.
3. Click **Log in**.

After signing in, you will see the projects you have access to.

## 2. Open Your Project

1. Click **Projects**.
2. Select your project.
3. Click the project name to open it.

## 3. View Issues and Features

1. Open your project.
2. Click **Issues**.
3. Review the list of Issues and Features.
4. Click an Issue or Feature to view its details.

You can review information such as:

- Subject
- Status
- Priority
- Assignee
- Description
- Due date
- Notes and comments
- Attachments
- Issue history

## 4. Add a Comment and Attach a File

Comments in Redmine are called **Notes**. You can add a comment and attach a screenshot or file at the same time.

1. Open the relevant **Issue or Feature**.
2. Scroll to the **Notes** section.
3. Click **Edit**.
4. Enter your comment.
5. Click **Choose File** to attach a screenshot or document, if needed.
6. Click **Submit**.

Your comment and attachment will be added to the Issue or Feature.

**Example:**

> The error is still occurring when I submit the form. I have attached a screenshot for reference.

## 5. Reply to an Existing Issue

When responding to an existing Issue or Feature, **add your response to the existing Issue instead of creating a new one**.

1. Open the Issue or Feature.
2. Review the previous Notes.
3. Click **Edit**.
4. Add your response.
5. Attach a file if needed.
6. Click **Submit**.

Create a new Issue only when reporting a **new or separate problem**.

## 6. Check for Updates

Open the Issue or Feature to check for updates.

Review:

- **Status**
- **Notes**
- **Assignee**
- **Attachments**
- **Issue history**

You can also check your email for Redmine notifications, depending on your notification settings.

## 7. Search for an Issue

If your project has many Issues:

1. Open **Issues**.
2. Use the available filters.
3. Filter by information such as **Status**, **Tracker**, **Assignee**, **Priority**, or **Subject**.
4. Apply the filter to find the Issue you need.

## Customer Workflow

Use this workflow when communicating with the project team:

**Sign in → Open Project → Open Issues → Select Issue/Feature → Review Updates → Add Note → Attach File (if needed) → Submit**
